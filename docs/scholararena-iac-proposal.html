IAC's Top 3 Priorities

📋 Assumptions: Priority ranking based on preliminary conversations. Will be validated during Phase 0 Discovery workshops with IAC stakeholders.

Priority 1: Enhanced Registration System

Most critical need. Replace manual processes with digital system that provides:

  • View Registrations — Parents see all children's registrations, teachers see students, admins see everything
  • Modify Registrations — Change/switch competitions before event starts (subject to availability)
  • Waitlist Management — Auto-waitlist when registration closes (12 days before event), auto-promote when spots open, email notifications, 48-hour acceptance window, $10 late fee surcharge
  • Duplicate Prevention — Block students from registering for same subject+question set combination (e.g., can't register for Blue History Bee twice, but can register for Red History Bee)
  • Multi-Portal Access — Parents, students (14+), teachers, and IAC admins all have role-specific dashboards

Priority 2: Qualification Data Connection & Automated Invitations

Second priority. Connect qualifying exam results directly into the competition lifecycle so qualified students are automatically guided to the next step:

  • CSV Upload (or API Sync) — Bulk import of students who passed qualifying exams; optional API integration with IAC's exam system for real-time sync
  • Eligibility Enforcement — Only qualified students can register for Nationals (and other gated events)
  • Automated Qualification Emails — As soon as a student qualifies, the system automatically emails the student and parent with:
    • Congratulations + which competition(s) they've qualified for
    • Direct one-click registration link (pre-filled with student info)
    • Event schedule, dates, location, and registration deadline
    • Stay-to-play and travel logistics info (where applicable)
    • Reminder emails if they haven't registered within X days
  • Dashboard Visibility — Students, parents, and teachers see qualification status, eligible events, and registration deadlines in their portals
  • Teacher/School Notifications — Teachers automatically notified which of their students qualified, with bulk-register option
  • Conversion Tracking — IAC admins see qualification → registration funnel (who qualified, who registered, who needs follow-up)

Priority 3: Statistics & History

Third priority. Unified profiles showing full competition history:

  • Student Profiles — All competition results in one place, career statistics, medals won
  • Cross-Event Tracking — Performance across subjects (History, Geography, Science) and years
  • School Statistics — School-wide rankings, historical performance, team achievements

Four-Portal Architecture

Each portal is tailored to its user group's specific needs, with appropriate permissions and workflows. All portals share a unified database ensuring data consistency across the platform.

How Portal Access Works

All users access the platform at iac.scholararena.com. After login, the system automatically routes each user to their appropriate portal based on their role:

User Role Portal URL Access Method
Parents iac.scholararena.com/parent/dashboard Automatic after login with parent account
Students (14+) iac.scholararena.com/student/dashboard Automatic after login with student account
Teachers iac.scholararena.com/teacher/dashboard Automatic after login with teacher account
IAC Staff iac.scholararena.com/admin/dashboard Automatic after login with admin account
💡 Multi-Role Support: Users with multiple roles (e.g., a teacher who's also a parent) can easily switch between portals using a role switcher in the navigation menu. Single login, multiple views — no need to log out and back in.
